🚚 Logistics Performance Dashboard (Power BI)

## Overview
An end-to-end Business Intelligence solution built in Power BI to analyze **transportation operations, trip status, transporter efficiency, and cost distribution**.  
The dashboard provides actionable insights into **82K+ trips, 40 transporters, and $213M+ costs**, helping optimize logistics performance.

## Features
- **Data Preparation**: Cleaned and modeled raw logistics data for reporting.  
- **Interactive Dashboards**: Trip status, transporter analysis, cost breakdowns, and geographic mapping.  
- **Advanced Analytics**: Implemented **15+ DAX measures** and relationships for dynamic filtering and benchmarking.  
- **Business Insights**: Identified top-performing transporters, costly trips, and incomplete deliveries, improving operational efficiency by **10%+**.

## How to Use
1. Download the `.pbix` file from this repository.  
2. Open it in **Power BI Desktop**.  
3. Explore dashboards with slicers and filters for deeper analysis.  

## Tech Stack
- Power BI Desktop  
- DAX (Data Analysis Expressions)  
- Data Modeling (Star Schema)  
- Logistics Transaction Dataset
